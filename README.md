# Nhóm 9 — Trả lời câu hỏi Biofilm Listeria

Trang hỏi–đáp của Nhóm 9 (CNSHTP) về màng biofilm của *Listeria monocytogenes* dưới stress thẩm thấu do NaCl trong chế biến thịt.

## Cách dùng

- Mở `index.html` (hoặc xem qua GitHub Pages).
- View 1: chọn **Xem câu trả lời của Nhóm 9** hoặc **Xem câu hỏi của Nhóm 9**.
- View 2: chọn nhóm để xem Nhóm 9 trả lời / hỏi nhóm đó là gì.
- Thanh tìm kiếm và lọc chạy theo đúng nhóm đang xem; 2 câu ngoài phạm vi vẫn hiện rõ với nhãn "Ngoài phạm vi" và lý do.

## Nội dung

- 13 câu các nhóm khác đặt cho Nhóm 9 (Nhóm 1, 2, 3, 4, 5, 6, 8): 10 câu trả lời đầy đủ, 1 câu trả lời một phần, 2 câu ngoài phạm vi.
- 16 câu Nhóm 9 đặt cho 8 nhóm khác (mỗi nhóm 2 câu), theo file câu hỏi phản biện ngày 08/11/2026. Mỗi câu gồm bối cảnh, vấn đề chính, câu hỏi và mục tiêu cần trả lời.

## Triển khai

- GitHub Pages được triển khai tự động bằng GitHub Actions (`.github/workflows/pages.yml`) mỗi khi push lên nhánh `main`.
- Tên miền tùy chỉnh: **https://cnshtp.yangio.id.vn** (khai báo trong `CNAME`).
